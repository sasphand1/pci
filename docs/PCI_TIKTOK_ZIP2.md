# TikTok public directory (ZIP 2)
Owner opens People > TikTok, collects a verified snapshot and explicitly publishes each eligible creator after checking Scrappa reuse permission. Unpublish revokes access; re-staging or relinking clears approval. Public data is an allowlisted projection of the latest coherent snapshot, no provider credentials, private identifiers or raw payloads. `/creators?platform=tiktok` supports search, five metrics and pagination; homepage, rankings and linked profiles display TikTok separately. No changes to combined YouTube/Instagram ranking engine. TikTok-only creators have directory cards, dedicated PCI profile pages and external profile links. No remote avatar publication: ZIP 1 intentionally omits avatar URLs from snapshots. Existing historical snapshots older than 15 days remain labelled but unranked, and snapshots older than 90 days are excluded. Migration 131 is mirrored in startup schema. Requires source reuse permission, Owner approval, successful builds and live validation. No local Docker requirement.
